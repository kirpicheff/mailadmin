# MailAdmin Roadmap 2026

Стратегический план разработки современной панели управления почтовыми серверами.

## 🎨 Design Guidelines (Единый стандарт)
*   **Стиль:** Premium Enterprise. Строгость, чистота и высокая плотность информации.
*   **Выравнивание:** Всегда по **левому краю** (заголовки, метки, контент). Никакого `text-right` для меток.
*   **Формы:** 
    *   Структура: Понятная группировка по смыслу (карточки внутри модалок).
    *   Инпуты: Стандартный цвет текста. **Запрещены** цветные шрифты для цифр/значений в полях ввода.
    *   Радиус: `rounded-xl` (12px) для контролов, `rounded-[32px]` для панелей.
*   **Таблицы:** Кнопки действий (Edit/Delete) всегда **центрированы** в своей колонке.
*   **Цвета:** Акцентный — `mail-blue`. Семантические цвета (зеленый/красный) только для статусов.

## Шаг 1: Аутентификация и Суперадмины (Core) ✅
*   **Бэкенд:**
    *   [x] Реализация JWT-авторизации.
    *   [x] Поддержка старых хешей (сравнение MD5-CRYPT) и новых (SHA512-CRYPT) при входе.
    *   [x] API для управления составом админов (`admin` table).
    *   [x] Разграничение прав: Супер-админ (видит всё) vs Админ домена (видит только свои домены).
*   **Фронтенд:**
    *   [x] Полноценная форма Login с обработкой ошибок 401.
    *   [x] Раздел «Настройки доступа» для управления администраторами.

## Шаг 2: Управление Доменами (Domains) ✅
*   **Бэкенд:**
    *   [x] CRUD API для таблицы `domain`.
    *   [x] Логика мягкого удаления (active=0) или полного удаления со всеми связями.
    *   [x] Расширенная статистика: динамический расчет почтовых ящиков, алиасов и занятых квот через SQL JOIN.
    *   [x] Валидация MX-записей через Go (проверка DNS в реальном времени).
*   **Фронтенд:**
    *   [x] Премиальная таблица доменов с поиском и фильтрацией.
    *   [x] Визуализация статистики прямо в списке через прогресс-бары.
    *   [x] Статус MX-записи с тултипом данных DNS.

## Шаг 3: Почтовые ящики (User Management) ✅
*   **Бэкенд:**
    *   [x] CRUD API для таблицы `mailbox`.
