# MailAdmin Roadmap 2026

Стратегический план разработки современной панели управления почтовыми серверами.

## 🎨 Design Guidelines (Единый стандарт)
*   **Стиль:** Premium Enterprise. Строгость, чистота и высокая плотность информации.
*   **Выравнивание:** Всегда по **левому краю** (заголовки, метки, контент).
*   **Радиус:** `rounded-xl` (12px) для контролов, `rounded-[32px]` для панелей.
*   **Таблицы:** Кнопки действий всегда **центрированы** в своей колонке.
*   **Цвета:** Акцентный — `mail-blue`. Зеленый/красный — только для статусов.

## 🏁 Завершено (Completed) ✅

### Шаг 1: Ядро и Авторизация (Core)
- [x] JWT-авторизация и разграничение ролей (SuperAdmin / Domain Admin).
- [x] Поддержка хешей SHA512-CRYPT и обратная совместимость с MD5-CRYPT.
- [x] Защита от IDOR на уровне бэкенда.

### Шаг 2: Управление Доменами
- [x] Полный CRUD для доменов и алиасов доменов.
- [x] Автоматическая проверка MX-записей.
- [x] **Диагностика DNS:** Генератор SPF/DKIM/DMARC записей и аудит безопасности.

### Шаг 3: Почтовые ящики и Фильтрация
- [x] Управление ящиками (Quota, Passwords, Active/Inactive).
- [x] **Sieve Filter Builder:** Мощный визуальный конструктор правил обработки почты.
- [x] **Advanced Autoresponder:** Многострочные автоответы с интервалами через Sieve.
- [x] Удаление устаревшего модуля Vacation (Legacy cleanup).

### Шаг 4: Мониторинг и Инструменты
- [x] **System Health:** Дашборд ресурсов (CPU, RAM, Disk, SSL, Services).
- [x] **Mail Queue:** Управление очередью Postfix (Просмотр/Flush/Delete All).
- [x] **Fail2Ban Manager:** Просмотр блокировок по всем тюрьмам и разбан IP в один клик.
- [x] **GeoIP Integration:** Определение страны заблокированного IP (через API браузера/бэкенд).
- [x] **Log Intelligence:** Смарт-парсинг логов Postfix/Dovecot и подсветка ошибок.
- [x] **Real-time Tail:** Интерактивное обновление логов в режиме реального времени.
- [x] **Backend Search:** Полнотекстовый поиск по логам через grep на стороне сервера.
- [x] **Журнал аудита:** Полная история действий с пагинацией и локализацией.
- [x] **Admin Tools:** Тестовая отправка писем и Broadcast рассылки.

## 🚀 Будущие задачи (Future Goals)

### 1. UX и Безопасность
- [x] **Quota Visualization:** Прогресс-бары использования места в списке ящиков.
- [x] **Password Strength Meter:** Индикатор сложности пароля при создании.
- [ ] **2FA for Admins:** Двухфакторная аутентификация через TOTP (с хранением секретов в изолированной таблице).

### 2. Управление доменами и интеграция
- [ ] **Catch-All Email:** Поддержка перенаправлений для доменов (через стандартную таблицу alias).
- [ ] **Autoconfig/Autodiscover:** Автоматическая генерация настроек для клиентов на основе MX-записей домена с проверкой активности в БД.

### 3. Продвинутые функции Sieve
- [ ] **Filter Priority:** Изменение порядка (Drag-and-drop) выполнения фильтров.
- [ ] **Global Filter Templates:** Шаблоны фильтров для быстрого применения к новым доменам.
